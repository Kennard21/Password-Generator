# 🔐 PyPassword Generator

A simple, secure web-based password generator built for **personal use** with Python and Streamlit.

## 🌐 Live Web App
Access and use the app directly from your browser (PC or mobile):
👉 **[Open PyPassword Generator](https://password-generator-exercise.streamlit.app/)**

## ✨ Features
- **Customizable Composition:** Choose the exact number of letters, symbols, and numbers (defaults to a strong 16-character password: 10 letters, 3 symbols, 3 numbers).
- **Cryptographically Secure:** Powered by Python's built-in `secrets` module for strong randomness.
- **One-Click Copy:** Easily copy generated passwords straight to your clipboard.

## 🛠️ Tech Stack
- **Language:** Python
- **Framework:** Streamlit
